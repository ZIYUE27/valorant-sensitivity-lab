# Valorant 灵敏度实验室

这是一个可直接部署到 GitHub Pages 的静态网页。所有测试记录仅保存在访问者自己的浏览器中。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，例如 `valorant-sensitivity-lab`。
2. 上传本文件夹中的全部文件：`index.html`、`README.md` 和 `.nojekyll`。
3. 打开仓库的 **Settings**，选择 **Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/(root)`，然后保存。
5. 等待 GitHub 显示网址，通常格式为：`https://你的用户名.github.io/valorant-sensitivity-lab/`。

## 使用

访问者填写自己的鼠标 DPI 和 Valorant 灵敏度后，即可在浏览器中完成五组灵敏度的对比测试。
